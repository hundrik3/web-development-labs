Лабораторная работа 9

9.html — история заказов.
lunch9.html — выбор блюд.
orders9.html — оформление нового заказа.
index.html — главная страница.

Распакуйте весь архив и откройте папку через локальный веб-сервер или разместите на хостинге. При использовании Live Server в VS Code нажмите правой кнопкой по 9.html и выберите Open with Live Server. Все страницы должны открываться с одного адреса сайта для общей корзины и ключа доступа.

Для API нужен персональный ключ из СДО Московского Политеха. Введите его в поле «Ключ доступа». Он хранится только в sessionStorage и не включён в исходный код.

«Подробнее» показывает заказ; «Редактирование» меняет контакты и доставку; «Удаление» запрашивает подтверждение. Используются GET, PUT и DELETE учебного API. Состав заказа при редактировании не меняется.

Проверено с контролируемыми ответами API: сортировка, стоимость, просмотр, заполнение формы редактирования, отмена, обработка ошибок, успешное изменение и удаление, обновление списка и сохранность текущей корзины. HTML и JavaScript проверены локальными валидаторами.
Настоящие изменение и удаление заказов не проверены: персонального ключа пока нет, учебный сервер недоступен. Резервных тестовых заказов в приложении нет.
