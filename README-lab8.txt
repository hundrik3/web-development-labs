Лабораторная работа 8

8.html — выбор блюд.
orders8.html — состав и оформление заказа.
index.html — главная страница.

Как открыть
1. Распакуйте весь архив и откройте папку в VS Code.
2. Запустите папку через локальный веб-сервер. Например, при наличии расширения Live Server нажмите правой кнопкой по 8.html и выберите Open with Live Server.
3. Также можно разместить все файлы на GitHub Pages или другом хостинге.
4. Переходите к оформлению через ссылку на странице меню.

Для сохранения выбора между страницами обе страницы должны открываться с одного адреса сайта. При открытии файлов напрямую через file:// поведение localStorage зависит от браузера.

Доступ к API
Персональный API-ключ выдаётся через СДО Московского Политеха. Введите его в поле «Ключ доступа». Ключ хранится только в сессии вкладки и не включён в исходный код.
Без ключа запросы не отправляются. Если API недоступен, появится сообщение и кнопка повторной загрузки. Локального резервного меню нет.

Что проверено
Выбор и восстановление ID блюд, удаление, сумма, допустимые комбо, сохранение заказа при ошибке, очистка после успешного ответа, время доставки и адаптивность проверены с контролируемыми ответами API.
Настоящая загрузка меню и создание заказа не подтверждены: на момент подготовки персонального ключа нет, а учебный API возвращает 502.
