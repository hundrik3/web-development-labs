Лабораторная работа 10

10.html и index.html — адаптивный лендинг Food Construct.
Локальный Bootstrap 5.3.9: vendor/bootstrap.min.css и vendor/bootstrap.bundle.min.js.
Собственные стили: css/landing10.css.

Используются Bootstrap Grid, navbar/collapse, карточки, кнопки и поля формы. На странице есть главный экран с фотографией, преимущества, переход в меню, обратная связь и контакты. Готовые шаблоны не использовались.

Откройте 10.html в браузере. Для переходов между выбором блюд и оформлением заказа запускайте всю папку через локальный сервер либо разместите её на хостинге. lunch9.html — меню, orders9.html — оформление, 9.html — история. Эти страницы используют учебный API и персональный ключ из СДО.

Обратная связь на лендинге — учебная форма POST на https://httpbin.org/post. Она не отправляет письмо компании. Контакты демонстрационные.
